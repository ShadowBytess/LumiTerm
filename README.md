```### LumiTerm

LumiTerm: A custom terminal by LuminousCat (@ShadowBytess) for CachyOS/Arch Linux.

This is a fully maintained environment until it becomes stable enough to abandon, as well as it is a passion project. If you wish to take this for yourself and continue maintaining it, please email me at my GitHub contact email to discuss a plan.

There are several known bugs at the moment:
- Typed text in the terminal does not show up unless it is a Fish shell autocomplete command (Untested with other shells)
- There could potentially be typing issues with other shells
- There are issues with cursors and configurations

I am currently working to fix these. If you would like to help, please email my GitHub contact email or submit an Issue/Pull Request to ask. Thank you.
